# Le cahier — app Android

Capte un cours au micro (même écran éteint), choisis la matière, puis envoie l'audio au cahier
(https://claude.ai/artifact/LmxeKaao9abFDJfXDurLL5). Le cahier ouvert sur le PC le transcrit et Claude en fait le cours.

- Les audios sont rangés dans `Téléchargements/Cahier`, nommés `Matière — Titre — date.m4a`.
- L'APK est construit par GitHub Actions à chaque push sur la branche `cahier-app` (onglet *Releases*).
