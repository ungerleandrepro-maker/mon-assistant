# Le cahier — app PC (Windows)

Fenêtre dédiée au cahier (https://claude.ai/artifact/LmxeKaao9abFDJfXDurLL5).
Fermer la fenêtre la range dans la zone de notification : le cahier continue de transcrire
les audios envoyés par l'app Android. Clic droit sur l'icône → « Lancer au démarrage de Windows ».

L'installateur est construit par GitHub Actions (onglet *Releases*).
